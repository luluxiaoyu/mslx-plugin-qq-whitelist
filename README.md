# MSLX 自助 QQ 白名单申请插件

基于 QQ 邮箱验证码认证的 Minecraft 自助白名单申请插件，玩家通过独立页面自主申请，管理员可在后台灵活管控。

- **插件 ID**: `mslx-plugin-qq-whitelist`
- **程序集**: `MSLX.Plugin.QqWhitelist`

---

## 功能特性

1. **三种白名单处理模式**：
   - **配置文件模式 (推荐)**：在线下发指令，离线直接读写 `whitelist.json`，开机直接载入生效。
   - **仅在线模式**：仅服务器运行时允许提交，关机时阻断申请并提示维护。
   - **开启后重放模式**：离线申请写入队列暂存，开机捕获就绪日志后自动补发指令。
2. **离线与正版 UUID 精准计算**：
   - 离线服基于标准 Java UUIDv3 算法精准计算，正版服自动调用 Mojang API 解析。
3. **全局 SMTP 发信策略**：
   - 宿主各实例共享发信配置，内置 QQ、163、Outlook 预设，支持一键发送测试邮件。
4. **独立公开申请页 (`/public/whitelist/:slug`)**：
   - 免登录访问，自动继承宿主登录壁纸毛玻璃效果，支持明暗主题切换与玩家 3D 头像预览。
   - 严格限制 5-10 位纯数字 QQ 号，内置防暴力破解与防浏览器误保存密码机制。
5. **真实服务器图标展示**：
   - 自动安全读取实例 `server-icon.png` 并在申请页面展示，内置沙箱隔离与文件安全校验。
6. **审计与一键撤销**：
   - 记录申请 QQ、游戏角色名、UUID、申请时间（服务器本机时区）及 IP，支持管理员一键撤销。

---

## 使用指南

### 1. 配置发信策略 (SMTP)
打开任意实例设置中的「自助 QQ 白名单」选项卡，点击「配置发信策略」，选择常用邮箱预设并填写发信账号及授权码，可点击「发送测试邮件」验证连通性。

### 2. 开启实例白名单申请
在目标实例的「自助 QQ 白名单」选项卡中：
1. 开启主开关；
2. 填写服务器展示名称与访问路径别名（Slug，如 `survival`）；
3. 选择白名单处理模式（推荐配置文件模式）；
4. 保存配置后，复制公开访问链接即可分享给玩家。

---

## 模板占位符

- **指令模板**：`{username}`（玩家游戏 ID）、`{uuid}`（玩家 36 位 UUID）
- **邮件模板**：`{server_name}`（服务器名称）、`{code}`（6 位验证码）、`{expire_minutes}`（有效期）
